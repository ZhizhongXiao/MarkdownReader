# MarkdownReader 设计文档

版本：1.0 发布候选

---

## 1. 项目定位

MarkdownReader 是一个离线 Markdown 文档阅读器生成工具。

它将一个或多个 Markdown 文件转换为独立 HTML，用于：

- 长文阅读
- 左侧目录导航
- 打印或导出 PDF
- 多文件资料索引

生成的 HTML 是项目的核心交付结果。GUI、CLI 和打包程序都只是围绕“生成可离线阅读的 HTML”提供入口。

MarkdownReader 不是：

- Markdown 编辑器
- 实时预览编辑器
- 在线文档服务
- 静态网站生成器
- 协作平台

## 3. 设计原则

### 离线优先

生成的阅读 HTML 应自包含，不依赖服务器、CDN 或网络连接。

### 阅读优先

功能以阅读、导航和打印为目标，不加入编辑器、同步、协作等非核心能力。

### 职责分离

Python 负责调度和组装，Node 负责 Markdown 渲染，浏览器负责阅读交互。

```text
Markdown
    ↓
Python 调度
    ↓
Node Markdown 渲染
    ↓
HTML 模板组装
    ↓
浏览器阅读
```

### 单文件交付

每个 Markdown 文件输出一个独立 HTML。索引页也输出为独立 HTML，CSS 和 JS 在生成时内嵌。

### 模板可维护

阅读器外壳由 `default` 模板提供，个性化主题通过模板继承覆盖视觉样式，不复制阅读器交互逻辑。

---

## 4. 模板设计

当前模板体系：

```text
templates/
    default/   共享基础阅读器模板
    modern/    清爽阅读主题
    office/    类 Word 正式文档和打印主题
    vscode/    类 VS Code Markdown Preview 技术主题
    index/     批量索引页模板
    viewer.js  共享阅读器交互
    print.css  共享打印样式
```

`default` 是阅读器外壳和兼容基底，负责：

- 工具栏
- 左侧目录
- 正文容器
- 基础排版
- 通用 CSS 变量

`modern`、`office`、`vscode` 是视觉主题，只覆盖必要样式。

`templates/index/` 用于批量索引页。索引页生成时读取 `index.html`、`theme.css`、`index.js`，再内嵌成单文件 HTML。

## 5. GUI 设计

GUI 使用 `pywebview`，只作为桌面操作入口。

GUI 负责：

- 文件/文件夹选择
- Windows 文件复选、资源管理器拖入和转换清单预检
- 输出目录选择
- 模板选择
- 转换选项
- 静态模板预览
- 日志展示
- 调用核心转换流程

转换清单采用无表头双行列表，默认突出状态、文件名、纳入方式和输出去向；点击文档行
展开完整源路径、完整输出路径、状态及警告。该布局用于避免窄窗口中的五列表头和横向
滚动。删除按钮独立于行展开操作，键盘用户可使用 Enter 或空格展开详情。

右侧工作区将“列表 / 预览”作为主要视图标签，标签宽度由内容决定且切换时位置保持稳定；
“日志”作为右侧次要入口，正常状态保持静默，仅在出现警告或错误时显示问题图标和数量。
活动标签和日志问题提示使用两套独立视觉状态，避免把“正在查看”误解为“出现异常”。

GUI 不负责：

- Markdown 解析
- TOC 生成
- 正文渲染
- 阅读器交互逻辑

配置保存为 `config.json`，在点击“开始转换”后写入应用目录。

## 6. 打印设计

打印是一等能力。

打印时应：

- 隐藏工具栏
- 隐藏左侧目录
- 隐藏返回顶部等交互控件
- 保持白底黑字
- 尽量避免标题孤行、图片截断、代码块截断、表格截断

Office 模板是打印优先模板；Modern 和 VS Code 只保证正常打印，不追求 Word 级分页一致。

---

## 7. 依赖策略

源码运行依赖：

- Python 3.11+
- Node.js 18+
- pywebview
- markdown-it / KaTeX 等 Node 依赖

面向普通用户发布时，应把 Windows 便携版 Node.js 放入：

```text
packaging/node/node.exe
```

最终 EXE 优先使用内置 Node；没有内置 Node 时回退到系统 `PATH` 中的 `node`。

---

## 8. 不做事项

当前版本明确不做：

- Markdown 编辑
- 实时编辑预览
- 云同步
- 多人协作
- 数据库
- Web 服务
- 插件市场
- 复杂网站生成

后续扩展应围绕阅读器生成、模板和打印体验展开。
