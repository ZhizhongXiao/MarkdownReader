自动打开 ✓：转换完成后应由默认浏览器打开索引页，地址形如 `file:///…`。
若地址是 `http://127.0.0.1:<随机端口>/`，那是 pywebview 为应用窗口自身起的内置服务
（`webview/__init__.py`：served using a local HTTP server on a random port），与转换产物无关，属预期。
自动打开失败的常见原因是系统里 `.html` 的默认应用不是浏览器（例如仍指向已停用的 IE）。

输出位置 ✓：单目录 + 保留目录结构时，整套产物落在「输出目录/源目录名-HTML/」下
（README.md 与 core/conversion_plan.py 的既定行为）：文件确实落盘，并不是被托管在某处。

观感基线 ✓（2026-09-23 起）：正文为左对齐（非两端对齐）；超长链接与裸文件名在容器内折行，不会被裁掉；
打印为白纸 + 跟随正文的主题块与左右框线；结果以 `file://` 打开，打不开时先检查系统 `.html` 的默认应用。
