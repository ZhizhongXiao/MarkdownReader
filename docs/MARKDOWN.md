# 兼容范围

本页说明当前版本对 Markdown 与原始 HTML 的处理范围。它描述的是**已经实现**的行为，不是路线图；
能力变化时同步更新本页与 [samples/demo.md](../samples/demo.md)。

迁移期间的能力分类、测试证据与新增语法门禁见 [迁移兼容矩阵](MARKDOWN_COMPATIBILITY.md)。

## 解析器与选项

渲染由本地 Node 完成，使用 markdown-it，配置为：

- `html: true`：保留原始 HTML，交给浏览器解释。
- `linkify: true` 并关闭模糊链接：带 scheme 的真实 URL 自动可点，而 `README.md`、`report.md`、
  `版本 1.2.3` 这类裸文件名保持文本，不会变成 `http://xn--…`。
- `breaks: false`：单个换行不产生 `<br>`，空行分段。
- `typographer: false`：不替换引号、破折号等符号。

插件：`markdown-it-footnote`（脚注）与 `markdown-it-texmath`（`$…$`、`$$…$$`、`\(…\)`、`\[…\]`，由 KaTeX 排版）。

## 支持的写法

| 类别 | 说明 |
| --- | --- |
| Front matter | 文件开头 `---` 块按 YAML 解析；`title` 作为页面标题（引号剥离），`---` 块与其他键不出现在正文里 |
| 标题 | H1–H6，生成目录与锚点；标题内允许行内元素，目录保留同样文本而不显示标记 |
| 行内 | 粗体、斜体、删除线、行内代码、反斜杠转义 |
| 链接与图片 | 标准 Markdown 链接与图片；裸 URL 自动识别；清单内 `.md` / `.markdown` 链接重写为生成的 HTML |
| 列表与表格 | 有序、无序与嵌套列表；GFM 表格与列对齐 |
| 代码 | 缩进与围栏代码块，语言标注保留；围栏内不做公式或链接处理 |
| 公式 | 行内与块级公式由 KaTeX 预渲染：`$…$`、`$$…$$`、`\(…\)`、`\[…\]`，以及 `\begin{equation}` / `\begin{align}` 这类 begin/end 环境（环境名为小写字母且 `\begin` 与 `\end` 同名；不覆盖全部 LaTeX 环境——`align*`、大写环境名、不配对的环境名都不解析）；只有文档真的出现公式时才内联 KaTeX 样式与字体 |
| 脚注 | `[^id]` 引用、脚注区块与返回链接 |
| 引用与分隔线 | `>` 引用，`---` / `***` 分隔线 |
| 原始 HTML | 行内与块级 HTML 原样保留：`<span>`、`<mark>`、`<details><summary>` 等由浏览器解释 |

## 明确不支持

以下写法保持字面文本，不会被渲染成组件：

- 任务列表 `- [ ]` / `- [x]`
- `==高亮==`、`++插入++` 等标记扩展
- Callout / Admonition（`> [!NOTE]`）
- Mermaid、PlantUML 等图表语法
- WikiLink（`[[页面]]`）
- 数学以外的自定义容器语法

需要这些效果时使用原始 HTML，或把内容预先渲染好再嵌入。

## 图片的处理

- 标准图片语法且指向**本地可读文件**：内嵌为 data URI，支持 `.png` `.jpg` `.jpeg` `.gif` `.webp` `.svg` `.bmp`。
- 网络图片（`http:` / `https:` / `//`）与已经写成 `data:` 的引用：保持原样。
- 无法读取的本地文件：保留原引用，并在日志中给出可读路径的提示。
- `file:` 图片引用不做特殊处理，按 markdown-it 的默认结果输出。
- 原始 HTML 中的资源引用不参与内嵌。

## 生成的 HTML

- 单文件自包含：阅读器 CSS、JavaScript、目录、正文与 KaTeX 字体都内联在 HTML 中。
- 不使用 CDN、不依赖服务器，离线可直接打开。
- 只声明系统字体名，不内嵌字体文件；缺少指定字体时由浏览器与系统回退决定显示。
