# Office 模板

面向正式文档的类 Word 主题，继承 `base` 的主题 token；布局、目录、折叠、灯箱、代码复制与共享打印
样式来自 `viewer/`，本主题只负责正式文档视觉与打印排版。适用于报告、论文、制度文件、审计与会计材料，以及经常打印或导出 PDF 的文档。

## 字体与正文

- 正文：`"Times New Roman", "Songti SC", "Source Han Sans SC", monospace`；中文优先 Songti SC，
  英文与数字优先 Times New Roman；代码用 `monospace`；不打包字体、不引用 CDN。
- 正文 10.5pt、固定行距 22pt、段前段后 0、首行缩进 2em、左右缩进 0。
- 标题、列表项、表格、引用、代码块、图片段落、块级公式与顶层 HTML 块不使用正文首行缩进。

## 标题

标题使用同一衬线文档字体，不继承正文缩进或 22pt 行距：

| 标题 | 字号 | 段前 | 段后 |
| --- | ---: | ---: | ---: |
| h1 | 16pt | 12pt | 6pt |
| h2 | 14pt | 9pt | 4pt |
| h3 | 12pt | 6pt | 3pt |
| h4 | 10.5pt | 3pt | 2pt |
| h5 | 10.5pt | 2pt | 0pt |
| h6 | 10.5pt | 0pt | 0pt |

## 打印

- 共享打印样式隐藏目录、工具栏、交互按钮与返回顶部按钮，并移除屏幕上的纸张阴影与工作区背景。
- 纸面为白纸，主题的浅蓝底与左右两条框线画在正文列上；关闭「背景图形」只丢蓝底，框线保留。
- 表格、图片、代码块、引用与块级公式尽量避免跨页截断；超宽表格沿用共享打印缩放规则。

## 限制

HTML 与 CSS 无法完全复制 Word 的分页行为：不同浏览器、字体环境和打印机在分页、表格拆分、
行高、字体替换与纸张处理上仍会有差异。
