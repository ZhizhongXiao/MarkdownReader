# MarkdownReader 阅读示例

## 从 Markdown 到阅读文档

MarkdownReader 将 Markdown 文件转换为适合**阅读、导航和打印**的 HTML 文档。学习笔记、技术说明和正式报告，可以使用同一份内容，选择不同的阅读模板。

阅读器样式、交互脚本和公式字体随 HTML 一起生成。本文不引用网络图片或外部附件，生成后可直接离线阅读。

> 专注内容，按需选择版式。通过左侧目录定位章节，通过顶部工具栏调整正文展开层级、切换明暗模式、启用自动编号或打印。

### 三种阅读风格

| 模板 | 阅读风格 | 适用内容 |
| --- | --- | --- |
| Modern | 舒展、清爽的通用排版 | 学习笔记、长篇资料、日常文档 |
| Office | 类 Word 的正式文档排版 | 报告、制度、打印材料 |
| VS Code | 紧凑的技术文档排版 | 开发笔记、代码说明、配置手册 |

模板改变文档的视觉呈现，共用目录导航、正文折叠、代码复制和打印等阅读功能。

## 快速开始

### 使用桌面应用

1. 打开 `MarkdownReader.exe`。
2. 点击“添加文件”选择本文，也可以拖入 Markdown 文件或文件夹。
3. 选择输出目录，以及 `modern`、`office` 或 `vscode` 模板。
4. 点击“开始转换”，在“列表”页签查看逐文件状态。
5. 完成后点击“打开 HTML”，在浏览器中阅读。

“预览”页签展示模板风格示意，不会实时渲染所选文档。勾选“自动打开”可在转换后自动打开阅读入口；批量转换时可按需生成索引、保留目录结构。

### 从源码启动

在项目根目录、已安装依赖的 Python 虚拟环境中执行：

```powershell
python main.py
```

随后在 GUI 中选择文件和模板。当前入口仅启动桌面界面，不处理文档路径或 `--template` 命令行参数。

源码运行需要 Python 依赖、Node.js、npm 渲染依赖以及 WebView2 Runtime。完整安装与构建步骤见项目 README。

## 排版与内容示例

### 文字强调与引用

正文支持**重点强调**、*斜体说明*、~~删除线~~和 `行内代码`。中文、English 与数字 2026 可以混合使用，便于编写日常笔记与技术资料。

> 阅读建议：先用目录了解结构，再展开需要关注的章节。较长的代码和表格可以横向滚动，避免打断正文阅读。

原始 HTML 也可以用于简单标注：<span style="background-color: #fff2a8; color: #312800;">需要复核的内容</span>，或 <span style="color: #9261c2;">补充说明</span>。复杂网页布局的打印效果仍取决于浏览器。

### 列表与步骤

整理一份资料时，可以按以下顺序进行：

1. 用标题组织章节。
2. 用表格比较信息。
3. 用代码块保留操作示例。
4. 用脚注补充背景与说明。

适合集中阅读的资料包括：

- 学习笔记
  - 概念梳理
  - 公式与例题
- 工作文档
  - 操作说明
  - 阶段总结

### 代码与字面符号

代码块可以复制，内容中的美元符号按原样显示，不作为公式处理：

```python
from pathlib import Path

source = Path("samples/demo.md")
print(f"阅读示例：{source.name}")
print("Budget: $100; remaining: $200")
```

### 行内与块级公式

行内公式适合嵌入解释，例如圆的面积 $A = \pi r^2$。较长的推导可以单独成段：

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i
$$

公式在本地由 Node.js 与 KaTeX 预渲染，生成的阅读页无需连接公式服务或 CDN。

### 脚注

在正文保留简短结论，将补充信息放入脚注，可以减少阅读干扰。[^reading]

[^reading]: 脚注支持从正文跳转到注释，再通过返回链接回到引用位置。本例仅使用文档内脚注，不依赖其他文件。

## 多级目录与编号

### 阅读层级

正文标题会生成左侧目录，支持跳转、滚动定位和目录折叠。顶部的展开、折叠按钮按层级调整正文显示范围。

#### 章节内容

较长的章节可以继续划分小节，帮助读者定位具体主题。

##### 补充说明

细节说明适合放在更深层级，按需展开阅读。

###### 备注

本文包含 H1 至 H6 标题，可用于观察多级目录的层次和缩进。

### 自动编号

点击顶部自动编号按钮，可以观察各级标题编号。此示例不在标题中手动添加序号，便于比较开启与关闭后的效果。

## 输出与资源

### 单文件和批量输出

单独转换 `demo.md` 会生成 `demo.html`。目录批量转换会收集 `.md` 和 `.markdown` 文件；启用“生成索引”后，可从索引页打开各个文档。

正文中链接到本次转换清单里的其他 Markdown 时，程序会按实际输出路径改写为 HTML 链接。未加入清单的目标不会被自动转换。

### 离线阅读的范围

阅读器 CSS、JavaScript 和公式资源内置于 HTML。源文档中的图片等外部资源不会自动复制或嵌入：相对路径需要在输出位置仍然有效，网络图片仍需联网加载。

本文不包含外部图片，因此也可作为不依赖附件的模板截图素材。

## 阅读与打印

明暗模式适合不同阅读环境；目录宽度可以拖动调整。浏览器会记录部分阅读设置与阅读位置。

打印时隐藏目录与工具栏，保留文档正文。Office 模板面向正式排版和打印场景；分页、字体替换和纸张缩放仍由浏览器及本机环境决定。
