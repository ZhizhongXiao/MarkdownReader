MDViewer Demo

项目简介

MDViewer 是一个离线 Markdown 文档阅读器生成工具。它将 Markdown 文件转换为独立的 HTML 文档，专为阅读、导航和打印场景优化。

核心目标

  • 高质量的阅读体验
  • 完全离线可用
  • 单文件输出，零依赖

适用场景

  • 技术文档离线阅读
  • 内部知识库导出
  • 文档归档保存

功能特性

核心功能

  • Markdown 转 HTML
  • 单文件输出，无外部依赖
  • 左侧目录导航
  • 点击目录跳转
  • 滚动同步高亮
  • 打印友好
  • TOC 折叠与展开
  • 正文标题折叠
  • 代码块复制
  • 图片点击放大
  • 阅读位置记忆

非目标

  • Markdown 编辑器
  • 静态站点生成
  • 在线服务

安装

pip install -r requirements.txt

使用方法

python main.py demo.md

生成的 HTML 文件可直接在浏览器中打开。

设计原则

一切设计都应提升阅读体验。 不要添加仅对编辑有益的功能。

单一文件原则

每个 Markdown 文件应生成恰好一个 HTML 文件。生成的 HTML 必须是自包含的，不得依赖：

  • 外部 CSS
  • 外部 JavaScript
  • CDN
  • 服务器
  • 网络连接

职责分离

层级 职责
Python 读取、解析、生成 TOC、填充模板
HTML 文档结构
CSS 布局、排版、主题、打印
JavaScript 导航、滚动同步、折叠

Python 层

  • 读取 Markdown 文件
  • 使用 markdown 库转换为 HTML
  • 提取标题生成 TOC
  • 填充模板并内嵌 CSS/JS

浏览器层

  • CSS Grid 双栏布局
  • TOC 交互与折叠
  • 正文折叠与同步
  • 图片 Lightbox
  • 代码复制

浏览器技术

使用原生浏览器 API：

  • IntersectionObserver — 实现 Scroll Spy
  • scrollIntoView() — 实现平滑跳转
  • addEventListener() — 事件处理
  • navigator.clipboard — 代码复制
  • localStorage — 阅读位置记忆

不引入 React、Vue、jQuery 等第三方库。

版本计划

  1. Phase 1 — 基本阅读器：Markdown 渲染、TOC、ScrollSpy、打印
  2. Phase 2 — 阅读体验优化：折叠、图片放大、代码复制、位置恢复
  3. Phase 3 — 易用性改进：工具栏、暗色模式、自动编号、TOC拖拽
  4. Phase 4 — 多文档支持：批量生成、交叉导航
  5. Phase 5 — 桌面应用：GUI、拖放、EXE 打包

3 Phase 3 功能

3.1 工具栏

顶部工具栏提供以下按钮：

  • 展开/折叠全部正文
  • 展开/折叠全部目录
  • 自动编号开关
  • 暗色模式切换
  • 打印

3.2 暗色模式

支持浅色和暗色两种主题，默认跟随系统设置。切换状态保存到 localStorage。

3.3 自动编号

为标题自动添加层级编号（1、1.1、1.1.1 等）。

如上方的 "1 Phase 1 功能" 和 "1.1 基本阅读" 已经包含手动编号，打开自动编号时不会重复编号。

3.4 TOC 宽度拖拽

鼠标拖动左侧目录与正文之间的分隔线，可调整目录宽度。宽度保存到 localStorage。

3.5 返回顶部

工具栏提供返回顶部按钮，页面右下角有浮动按钮（滚动超过 300px 时自动显示）。

Phase 2 新增功能详解

TOC 折叠

点击目录中的箭头（▼/▶）可以折叠或展开子标题。

  • 仅影响目录显示
  • 与正文折叠状态保持同步
  • 打印时自动展开所有内容

正文标题折叠

每个标题前有一个折叠按钮，点击可以隐藏该标题下的所有内容，直到下一个同级或更高级标题。

类似于 Microsoft Word 的标题折叠功能。

代码块复制

每个代码块右上角有一个"复制"按钮，点击即可将代码内容复制到剪贴板。

图片点击放大

点击正文中的任意图片，将以 Lightbox 形式全屏显示。再次点击任意位置关闭。

打印时图片保持正常尺寸。

阅读位置恢复

关闭浏览器前自动记录当前滚动位置，再次打开时自动恢复。
