# Office 模板

Office 是面向正式 Markdown 输出的类 Word 文档模板，适用于报告、论文、制度
文件、审计与会计材料，以及经常打印或导出 PDF 的文档。

## 使用方式

运行 `python main.py` 启动 GUI，添加文档后选择 `office` 模板并开始转换。当前入口仅启动 GUI，不处理文档路径或 `--template` 命令行参数。

模板继承共享的 `default`，因此复用阅读器布局、目录行为、折叠、图片放大、
代码复制、表格包装和共享打印样式。

Office 只负责正式文档视觉与打印排版，不复制 TOC 生成、正文折叠或 Markdown 渲染逻辑。

## 字体规则

- 正文字体：`"Times New Roman", "Songti SC", "Source Han Sans SC", monospace`
- 中文优先使用 Songti SC，备选 Source Han Sans SC
- 英文和数字优先使用 Times New Roman
- 代码使用 `monospace`
- 不打包字体文件，不引用 CDN 字体

## 正文排版

普通段落采用常见 Word 文档设置：

- 字号：10.5pt
- 固定行距：22pt
- 段前：0pt
- 段后：0pt
- 首行缩进：2em
- 左右缩进：0

标题、列表项、表格、引用、代码块、图片段落、块级公式和顶层 HTML 块不使用
正文首行缩进。

## 标题间距

标题使用相同的衬线文档字体，不继承正文缩进或固定 22pt 行距。

| 标题 | 字号 | 段前 | 段后 |
| --- | ---: | ---: | ---: |
| h1 | 16pt | 12pt | 6pt |
| h2 | 14pt | 9pt | 4pt |
| h3 | 12pt | 6pt | 3pt |
| h4 | 10.5pt | 3pt | 2pt |
| h5 | 10.5pt | 2pt | 0pt |
| h6 | 10.5pt | 0pt | 0pt |

打印时会尽量避免标题孤立在页尾。

## 打印优化

- 共享打印 CSS 会隐藏目录、工具栏、交互按钮和返回顶部按钮
- 移除屏幕纸张阴影、边框和灰色工作区背景
- 打印强制使用白底黑字
- 表格、图片、代码块、引用和块级公式尽量避免跨页截断
- 超宽表格继续使用共享打印缩放规则

## 与 Modern 的区别

Office 具有以下特点：

- 灰色工作区中的类 Word 白色纸张
- Times New Roman 与 Songti SC / Source Han Sans SC 字体组合
- 10.5pt 字号与固定 22pt 行距
- 正文首行缩进两字符
- 类 Word 的标题字号和段落间距
- 清晰表格边框及克制的引用、代码样式
- 保留共享阅读器工具栏和目录外壳
- 目录标题编号分栏沿用共享阅读器结构，避免与其他模板产生交互差异

## 限制

HTML 和 CSS 无法完全复制 Word 的分页行为。不同浏览器、字体环境和打印机可能
在分页、表格拆分、行高、字体替换及纸张处理方面产生差异。
