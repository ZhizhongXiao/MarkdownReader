# Modern 模板

通用阅读主题，继承 `default` 的阅读器外壳、工具栏、目录结构与交互，只覆盖视觉。

## 适用

日常 Markdown 阅读、学习笔记、轻量文档、长篇资料与非正式打印。视觉目标是舒适的现代阅读器，
而不是代码编辑器、Office 文档或文档网站。

## 风格

- 柔和的浅色背景与中等宽度的阅读栏
- 细微的左侧引导线，不使用纸张卡片或完整边框
- 正文基准字号 16px、行高 1.8，正文左对齐
- 目录间距舒展、层级清楚；代码块清晰但不过度突出
- 以浅色模式为主，同时保证深色模式可用

标题编号与标题文本的分栏由共享目录结构承载，Modern 只调整视觉间距与颜色。

## 与另外两套的区别

- 与 VS Code：Modern 更宽松、平静；需要紧凑目录或编辑器式代码呈现时选 `vscode`。
- 与 Office：不使用类 Word 字体、固定行距、正文首行缩进或纸张阴影；正式报告与打印优先选 `office`。
