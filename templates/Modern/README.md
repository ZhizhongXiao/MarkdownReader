# Modern 模板

Modern 是 MDViewer 的通用阅读主题。

它适合日常 Markdown 阅读、学习笔记、轻量文档、长篇资料和非正式打印。
视觉目标是舒适的现代阅读器，而不是代码编辑器、Office 文档或文档网站。

Modern 继承 `default` 的阅读器外壳、工具栏、目录结构和交互逻辑，只覆盖主题视觉。

## 风格

- 柔和的浅色背景
- 中等宽度的阅读栏
- 使用细微左侧引导线，不使用纸张卡片或完整边框
- 正文基准字号 16px，行高 1.8
- 目录间距舒展、层级清楚
- 代码块清晰但不过度突出
- 以浅色模式为主，同时保证深色模式可用

标题编号与正文标题文本的分栏由共享 TOC 结构承载，Modern 只调整其视觉间距和颜色。

## 与 VS Code 的区别

Modern 更宽松、平静，使用两端对齐正文、柔和蓝色强调和较舒展的目录。

代码较多、需要紧凑目录或偏好编辑器式 Markdown Preview 时，应选择 `vscode`。

## 与 Office 的区别

Modern 不采用类 Word 字体、固定 22pt 行距、正文首行缩进或纸张阴影。
正式报告和打印优先文档应选择 `office`。
