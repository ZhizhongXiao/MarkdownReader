# Default 基础模板

`default` 是 MarkdownReader 的共享基础模板，提供：

- 阅读器共用布局
- 通用主题变量
- 工具栏和目录外壳样式
- TOC 行结构、编号/标题分栏的共享视觉承载
- 供子模板继承的兼容样式

它主要用于兼容和继承，不作为首选个性化阅读主题。面向用户时通常选择：

- `modern`：通用现代阅读器
- `office`：正式文档与打印
- `vscode`：编辑器预览风格的技术阅读

不要在基础模板中加入强烈品牌化或特定文档风格，应将这些规则放入子模板。

TOC 的标题提取和编号拆分由 Python/Node 生成层完成，`default` 只负责共享外壳和
可继承的排版结构。
